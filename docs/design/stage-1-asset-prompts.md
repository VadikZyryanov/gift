# Иллюстрации первого этапа

Режим: встроенный `image_gen.imagegen`, без CLI/API key. Референс для всех предметов: [утверждённый макет](assets/main-scene-approved.png). Сгенерированы отдельные прозрачные предметы без текста; подписи добавляет React. PNG-оригиналы сохранены инструментом отдельно, рабочие WebP находятся в `src/assets/scene/`. Оптимизация: `cwebp -q 82 -alpha_q 90 -m 6 -resize <width> 0`, прозрачность сохранена.
