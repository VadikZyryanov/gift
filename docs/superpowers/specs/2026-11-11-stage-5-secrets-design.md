# Этап 5 — три личные пасхалки и вращение сундука

Дополнение к [концепции](2026-11-10-romantic-gift-game-design.md) и
[этапу 5 плана](../plans/2026-11-10-romantic-gift-game-implementation.md).

## Согласовано с владельцем

- Ровно три темы: зелёное платье с предложения, любимый белый Bueno и чёрный
  Mercedes Гелик. Они заменяют прежние черновые темы песни, лапок и открытки.
- Гелик: маленькая потёртая наклейка на задней стенке сундука. Сундук вращается
  вокруг вертикальной оси Y прямо на столе горизонтальным движением пальца.
  При отпускании мягко доворачивается до ближайшей передней/задней стороны.
  Находка засчитывается по нажатию на наклейку.
- Bueno: белая обёртка выглядывает из-за нижнего правого букета на главном столе;
  касание раскрывает шоколадку и записку о повседневной заботе.
- Платье: уголок карточки выглядывает из-за иллюстрации в мешочке «Один вопрос»;
  касание выдвигает карточку с платьем и воспоминанием о предложении.
- Владелец поручил пока нарисовать платье на усмотрение исполнителя;
  узнаваемый рисунок по личной фотографии сделаем позже.
- Bueno он постоянно покупает ей; особенно нравится белый. Чёрный Гелик
  подходит ей по вайбу, и владелец хотел бы когда-нибудь его подарить.

## Подход и варианты

Обсудили вращение прямо на столе и отдельный крупный план для осмотра.
Владелец выбрал стол: находка остаётся частью основной сцены без перехода.
Рисунок платья выбран временно вместо личной фотографии.

Технический выбор исполнителя: иллюстрированное CSS 3D-вращение с лицевой,
задней и боковыми гранями, без новых production dependencies. Существующую
лицевую иллюстрацию сохранять в DOM, чтобы не вернуть прежнее мерцание.

## Поведение и границы

- Вертикальный жест прокручивает страницу; горизонтальный вращает только
  сундук. После вращения не происходит случайного открытия/находки.
  Отмена жеста возвращает устойчивую сторону. Нажатие на лицевую сторону
  сохраняет проверку замка/открытие с четырьмя ключами.
- Обратная сторона доступна при любом количестве ключей, включая после финала.
  Скрытая сторона не принимает нажатия/фокус. Клавиши влево/вправо позволяют
  перевернуть сундук; названия предметов осмысленны для screen reader.
- Bueno доступен на главном столе с самого начала; карточка доступна до и после решения задания. Видна небольшая
  деталь без надписи «секрет»; удобная область касания не менее 44×44 CSS px.
- Каждая находка сохраняется до анимации, засчитывается один раз и открывает
  иллюстрацию с личной запиской. Повторное касание позволяет перечитать её.
  Закрытие возвращает к предмету и текущему ответу; reload сохраняет находку,
  но не проигрывает анимацию/звук и не восстанавливает временную записку.
- До финала общего счётчика нет. В финале впервые показываем 0–3 из 3,
  найденные предметы и дополнительное послание при всех трёх. Можно вернуться
  за пропущенным и получить бонус без повторного решения заданий.
- Все тексты записок и бонуса — редакционные черновики, основанные на
  подтверждённых фактах. Гелик в записке — мечта, не пункт подарочного листа.
- Reduced motion убирает протяжённые движения; все действия доступны сразу.
  Эффект находки только при добровольно включённых звуках, без смешения с голосом.
- Угол вращения и открытая записка не входят в сохранение. Текущие задания,
  ключи и открытое письмо сохраняются при обновлении. Старые служебные secret ID
  можно удалить из сохранения отдельной миграцией, не обнуляя остальной прогресс.
- Ни hover/focus-эффектов, ни новых production dependencies. Работать в текущем
  checkout; commit/push и публикация только по отдельному запросу.

Переделка открытия после четвёртого ключа, вращение конверта, письмо отдельным
листом, переход к реальному подарочному листу и замена звуков остаются
[отложенными замечаниями](../../design/2026-11-10-finale-feedback.md).

## Проверка

Unit/component: новые ID, миграция без потери ключей, одно начисление,
перечитывание, финал 0/3 и 3/3. Browser: настоящие горизонтальные/вертикальные
жесты, отмена и быстрый повтор, отсутствие открытия после свайпа, keyboard,
прежний замок, reload, оба порядка поиска, отсутствие изображений, reduced
motion и узкий экран/крупный текст. Физический iPhone/Яндекс проверяет владелец.
